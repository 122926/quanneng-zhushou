把手机网页版部署到云端后：**电脑关机也能用，手机在任何网络（流量 / Wi-Fi）都能打开**，不依赖这台电脑。

## 二、前置准备（5 分钟）

1. 有 DeepSeek API Key（没有就去 https://platform.deepseek.com 注册 → 创建 API Key，充值 10 元够用很久）。
2. 微信扫码登录 https://cloud.tencent.com ，完成实名认证（免费）。

## 三、部署（约 15 分钟，只操作一次）

1. 打开 https://console.cloud.tencent.com/scf ，进入云函数控制台。
2. 点「新建」/「创建函数」→ 选「从头开始」/「自定义创建」：
   - 函数名称：`quanneng-zhushou`
   - 地域：选离你近的（广州 ap-guangzhou 或深圳）——**不要选香港/海外**（访问慢）
   - 运行环境：**Python 3.9**（或 3.6+ 均可）
   - 创建方式：**在线编辑**（控制台默认就是代码编辑页）
3. 用记事本打开本目录的 `scf_handler.py`，全选复制，**粘贴覆盖**控制台编辑器里的全部内容，然后点「保存」→「部署」（右上角或底部）。
4. 切到「函数配置」页：
   - **执行超时时间：改成 180 秒**（默认只有几秒，等 DeepSeek 回复会超时报错——最容易踩的坑）
   - 内存：128MB 或以上（默认即可）
   - 「环境变量」→ 添加一行：键 `API_KEY`，值你的 DeepSeek API Key → 保存。

### 可选：配多组 API（最多 3 组，失败自动切换）

只配 `API_KEY` 一组照常使用；想用多家模型 / 多个 Key 容灾，按下面加：

| 组 | 必填变量 | 可选变量 |
| --- | --- | --- |
| 组 1 | `API_KEY_1`（或旧 `API_KEY`） | `API_BASE_URL_1`、`API_MODEL_1`、`API_NAME_1` |
| 组 2 | `API_KEY_2` | `API_BASE_URL_2`、`API_MODEL_2`、`API_NAME_2` |
| 组 3 | `API_KEY_3` | `API_BASE_URL_3`、`API_MODEL_3`、`API_NAME_3` |

- 不指定模型时按顺序自动尝试，某组失败（Key 失效 / 额度用完 / 超时）自动换下一组；
- 请求体带 `provider: "1"|"2"|"3"` 可指定用哪组。
- 示例：组 1 DeepSeek、组 2 豆包（`API_BASE_URL_2` 填 `https://ark.cn-beijing.volces.com/api/v3/chat/completions`，`API_MODEL_2` 填火山方舟接入点 ID）。

5. 切到「触发管理」→「创建触发器」：
   - 触发方式：**函数 URL**（API 网关触发器已下线，函数 URL 是官方替代）
   - 授权类型：**NONE（无需鉴权）**；公网访问：**开启**
   - 创建后，页面显示一个 URL，形如 `https://<app-id>-<url-id>.ap-guangzhou.tencentscf.com` ——**这就是你的网址，永久不变，复制保存**。
6. 浏览器打开这个 URL：能看到「全能助手」界面就成功了。发一句话测试，能收到回复即完成。

### 如果打开网址报错

- 404 / 路径不存在：多半是代码没部署成功，回到编辑器重新点「部署」；或检查 URL 是否复制完整。
- 提示超时 / 网关错误：多半是「执行超时时间」没改成 180 秒，回第 4 步改掉再部署。

## 四、手机使用

- 手机浏览器打开你保存的 URL 即可，**不要求同一 Wi-Fi，电脑可以关机**，流量也行。
- 建议手机桌面添加书签或「添加到主屏幕」，用起来像 App。
